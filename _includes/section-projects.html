{%- comment -%} Base list: apply the `archived` / `forks` exclusions from _config.yml. NOTE: Liquid has no `&&` operator - it silently parses only the left-hand side and discards the rest. Always use `and` here. {%- endcomment -%} {% if site.projects.exclude.archived and site.projects.exclude.forks %} {% assign visible_repos = site.github.public_repositories | where:'archived', false | where:'fork', false %} {% elsif site.projects.exclude.archived %} {% assign visible_repos = site.github.public_repositories | where:'archived', false %} {% elsif site.projects.exclude.forks %} {% assign visible_repos = site.github.public_repositories | where:'fork', false %} {% else %} {% assign visible_repos = site.github.public_repositories %} {% endif %} {%- comment -%} Two-key sort of the remaining repos. Liquid's `sort` filter takes a single property, and Jekyll implements it with Ruby's `sort!`, which is NOT stable - so sorting twice does not reliably produce a secondary ordering. Instead we build one composite string key per repo and sort those: stars are offset by 1000000 -> fixed 7-digit width, so a lexicographic compare matches a numeric one; `pushed_at` is ISO-8601, so lexicographic already equals chronological. `~` is a safe delimiter because Github repository names cannot contain it. `sort_by: stars` puts stars first and pushed second; anything else flips them. {%- endcomment -%} {% assign rest_keys = '' %} {% for repository in visible_repos %} {% unless site.projects.featured contains repository.name %} {% unless site.projects.exclude.projects contains repository.name %} {% assign stars_key = repository.stargazers_count | plus: 1000000 %} {% if site.projects.sort_by == 'stars' %} {% assign entry = stars_key | append: '~' | append: repository.pushed_at %} {% else %} {% assign entry = repository.pushed_at | append: '~' | append: stars_key %} {% endif %} {% assign rest_keys = rest_keys | append: entry | append: '~' | append: repository.name | append: ',' %} {% endunless %} {% endunless %} {% endfor %} {% assign sorted_rest = rest_keys | split: ',' | sort | reverse %}
